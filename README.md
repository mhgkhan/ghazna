# Ghazna

Welcome to **Ghazna** — a personal portfolio and blog-level website crafted by [Hasnain](mailto:muhammadhasnainghazna@gmail.com). This project showcases my work, thoughts, and technical journey, featuring robust user and blog management systems.

## 🚀 Live Demo

Check out the deployed site: [https://ghazna.online](https://ghazna.online)

## 📦 Repository

GitHub: [github.com/mhgkhan/ghazna](https://github.com/mhgkhan/ghazna)

---

## ✨ Features

- **Personal Portfolio:** Highlight My projects, skills, and achievements.
- **Dynamic Blog:** Create, edit, and manage blog posts with ease.
- **Advanced User Management:** Secure authentication, profile management, and role-based access.
- **Modern UI/UX:** Responsive and accessible design for all devices.
- **SEO Optimized:** Built with best practices for discoverability.

---

## 🛠️ Tech Stack

- **Frontend:** Next.js, React, Tailwind CSS
- **Backend:** Next.js, 
- **Database:** MongoDB 
- **Authentication:** JWT 
- **Deployment:** Vercel
